# Hero font assets

Latin WOFF2 files from the Google Fonts distribution; self-hosted for the hero.
Each font's SIL Open Font License is included beside its file.

- Inter: https://fonts.google.com/specimen/Inter
- Space Grotesk: https://fonts.google.com/specimen/Space+Grotesk
- JetBrains Mono: https://fonts.google.com/specimen/JetBrains+Mono

Only the `Hero Inter`, `Hero Space`, and `Hero Mono` CSS family aliases use these
fonts. The application's existing global font families are unchanged.
